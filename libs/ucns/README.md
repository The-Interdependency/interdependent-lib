## What it is

UCNS is in a definition-first restart. The current producer does not satisfy
the former `ucns>=0.9.1` convergence range and does not expose the archived
recursive-object API described by earlier releases.

The upstream source repo also carries the formal Lean scaffold for Theorem N.
That formal layer now depends on Mathlib in `formal/lakefile.lean`; Mathlib is a
Lean/formalization dependency, not a Python runtime dependency of `ucns`.

Current UCNS capabilities and option identities are authoritative only in the
current UCNS repository. Archived factorization objects and theorem scaffolds
do not transfer into this meta-package.
